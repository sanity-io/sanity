Generated by `npm run map`. Every count and every Tier/Audit value is read from

## How to walk it

The sidebar is a reading order, not a taxonomy. Alphabetical sorting applies only _inside_
a group. Read top to bottom and each movement earns the next: the ground floor is the
standard you will judge everything else against.

For an inspection pass, three questions per page:

1. **Does the metadata table tell the truth?** Source path resolves, Tier is defensible,
   Audit reflects what the stories actually show.
2. **Do the stories cover the states that matter?** Not just the happy path: empty, error,
   loading, permission-denied, and whatever the Audit row claims.
3. **Does the prose open by saying what the thing is?** If sentence one is an argument
   rather than an identification, it is on the rewrite list.
