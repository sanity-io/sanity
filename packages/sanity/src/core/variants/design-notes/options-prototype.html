F and G — rename the outer tabs

The tab called History is not an archive: it is a paginated event list whose rows set the since/rev range the diff renders. It is a picker, and the component behind it is already named EventsTimeline. Both options below rename the outer pair to Timeline · Compare. They differ on whether the version axis lives in the diff (F) or in the picker (G).
